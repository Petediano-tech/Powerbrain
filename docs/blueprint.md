# **App Name**: Power Brain - Malawi Smart Learning & Teaching Hub

## Core Features:

- Personalized Home Dashboard: Display personalized welcome message, study progress, recent quizzes, and motivational quotes to engage students.
- Interactive Quizzes: Offer diverse question formats with time-based challenges and leaderboards for effective exam preparation.
- AI Study Assistant: Built-in AI Study Assistant that acts as a chatbot, providing topic explanations, summarizing notes, and generating practice questions with adaptive language.
- Notes & PDF Section: Enable students and teachers to upload, download, and read notes and textbooks, with integrated PDF viewer and cloud synchronization.
- Teacher's Corner: Secure teacher login with tools to upload lessons, view performance charts, send assignments, and communicate with students. Also, an AI grading tool marks quizzes and provides feedback automatically.
- Student Profile & Progress Tracking: Personalized dashboard showing study streaks, time studied, quizzes completed, topics mastered, and AI-generated insights into the student's strengths and weaknesses using study data as a tool for analysis.
- Offline Access: Enable access to lessons, quizzes, and notes offline for continuous learning in areas with limited internet connectivity. All data can later be synced to the cloud.

## Style Guidelines:

- Primary color: Eggplant Purple (#6A0DAD) symbolizes wisdom and creativity, aligning with the educational focus of the app. This selection diverges from the more obvious 'blue for education', instead aiming for a rich and contemporary feel.
- Secondary color: Black (#000000) provides an AMOLED-friendly background that's easy on the eyes.
- Accent color: Gold (#FFD700) to highlight important elements and add a touch of sophistication, and Sky Blue (#64B5F6) for CTAs
- Font: 'Poppins' (sans-serif) for clear and accessible readability across all devices.
- Use minimalistic and educational icons relevant to each subject, ensuring they are easy to understand at a glance.
- Rounded UI elements and large tap targets ensure easy navigation and a user-friendly experience on mobile devices.
- Subtle animations (fade, slide-in, hover glow) provide engaging feedback and a dynamic user interface without being distracting.
